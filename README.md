# Easy Venn

A minimal website for creating Venn diagrams.

**Website:** https://easy-venn.vercel.app/

## Getting Started

- Start with one circle or a classic layout of two or three overlapping circles.
- Use **Main Menu** to return to the starting screen.

## Editing Circles

- Add or delete circles and rename them from the circles list.
- Click a circle to select it. Only one circle can be active at a time.
- Drag the active circle to move it.
- Scroll the mouse wheel or use the size buttons to resize it.
- Choose a snapping increment to move and resize circles by consistent amounts.
- Use **Center Active Circle** to move the selected circle to the canvas center.

## Colors and Fills

- Customize each circle’s color, opacity, and texture.
- Use **Fill Area** to color a circle region or an intersection. The default fill color is black.
- Region fills stay attached to their circle combinations when circles move or resize.
- Use **Unfill Area** to remove a region fill and restore the underlying circle colors.
- The canvas background cannot be filled.

## Exporting

- Export as **JPG** with a white background or **PNG** with no background.
- Choose **No Margin** to crop tightly around the diagram.
- Choose **Perfect Square** to center the diagram in a square image with balanced margins.
- Image size and quality are handled automatically.

## Other Controls

- Undo and redo changes.
- Diagrams are saved automatically in the current browser.
